- คง JSX/CSS, URLs, layouts, labels, navigation, responsive behavior, forms, modals และผลของ mock flows เดิม; บันทึก security/logic fixes แยกจาก visual regressions.

- ไม่สร้างบัญชีสมาชิก/OTP/payment จริง, Conference staff tab/SSO, heavy state/form library หรือ distributed services; ไม่ย้าย staff users/password hashes/sessions.
- Browser ใช้ allowlisted same-origin metadata routes; file bytes ใช้ explicit upload exception ไป Render ด้วย one-use opaque ticket ไม่ผ่าน Next file proxy (Vercel 4.5MB cap); server ใช้ getServerConfig()/absolute backendFetch; secrets ไม่เข้า client bundle/repo/log; session secret แยกจาก Conference JWK.
- Private staff/member responses ใช้ no-store; public cache policy/invalidation ใช้ interface ของแผน 02 ไม่เปลี่ยนเป็น shared private cache.
- Academy mutation derive actor จาก verified mock session ที่ Next เท่านั้น; backend ตรวจ server-only bridge trust ก่อนรับ actor; browser body/query/header ไม่มีอำนาจ override identity.
- Transactions ไม่ข้าม domain SQL ownership; stageUpload/reserveAttach สร้าง durable pending pin ก่อน domain transaction; confirmAttach/release หลัง commit; failure retain bytes/retry cleanup, ไม่มี destructive expiry sweeper และ crash pins reconcile เฉพาะ controlled write freeze ตามแผน 02.
- แผนนี้เขียนเอกสารเท่านั้น; ห้าม product edits/install/live DB/Conference mutation/signing/private-key copying/deploy ระหว่าง planning; commits ด้านล่างเป็นขั้น execution ในอนาคต.

1. Concurrent/replayed mock order/refund และ write failure ต้องไม่มี paid order ที่ไม่มี enrollment หรือคืนเงินครึ่งรายการ — Task 2.
