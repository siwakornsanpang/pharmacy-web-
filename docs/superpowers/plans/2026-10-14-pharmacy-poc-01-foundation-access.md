> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** วาง npm workspace, contracts/config และ staff authentication/authorization ที่ตรวจจริง เพื่อให้แผน domain และ migration ทำต่อโดยไม่เปลี่ยน UI เดิม

**Architecture:** POC มี Next frontends สองแอปกับ Fastify backend หนึ่งบริการ; domain ใช้ public contracts และ Access interface แทนอ่าน private tables ข้ามโมดูล Backend ออก JWT และตรวจ session/account/grants ปัจจุบัน ส่วน Backoffice Next server เก็บ bearer token ใน HttpOnly cookie และ proxy เฉพาะ routes ที่ประกาศ

**Tech Stack:** npm workspaces, TypeScript, Next.js 16.1.6/React 19.2.3 เดิม, Fastify, Drizzle/pg, bcryptjs, @fastify/jwt, node:test/app.inject และ Vitest ที่มีอยู่

- “Browser client ใช้ same-origin /api ที่มี allowlist ของ method/path/query และ fixed upstream จาก env” — convention ของ backend proxy คือ `/api/backend`
- JSON metadata/auth calls ผ่าน Next proxy; file bodies ขนาดใหญ่ใช้ bounded opaque upload-ticket exception ของแผน 02 ส่งตรงไป fixed Render upload endpoint เท่านั้น เนื่องจาก [Vercel Functions request/response payload limit 4.5 MB](https://vercel.com/docs/functions/limitations); ไม่ส่ง 100 MiB ผ่าน Next และไม่ส่ง staff JWT ให้ browser
- “Cookie-based mutations ตรวจ same-origin และ CSRF token” และ “ไม่ cache staff/member responses ข้ามผู้ใช้”
- เก็บ versions/overrides จาก source inventory ก่อน copy และตรึงกับ baseline แผน02Task1; `.nvmrc` pin `24.19.0` ตรง runtime ที่ตรวจแล้ว, engines/CI ใช้ Node major 24; ตรวจ provider compatibility ใน deployment phase โดยไม่เปลี่ยน framework majors แฝง ย้าย `react-simple-maps` override ไป root; ไม่ติดตั้ง/รัน product commands ในรอบเขียนแผน

- ไม่สร้าง generic controller/repository framework, distributed services, package registry จริง หรือ live projects ในแผนนี้; ห้าม secrets ใน Git, command args, snapshots หรือ logs
