- คง JSX/CSS, URLs, layouts, labels, navigation, responsive behavior, forms, modals, editor/crop/upload interactions และผลของ mock flows เดิม
- ใช้ GitHub repository ใหม่หนึ่งแห่งสำหรับ POC แยก deploy สามแอปด้วย npm workspaces และ lockfile กลาง

- Media ใช้ asset identity/object path และเจ้าของที่ตรวจได้ ไม่ลบตาม arbitrary URL ที่ client ส่งมา
- ไม่ import users rows, usernames/password hashes หรือ users sequence เดิม
- แผนนี้ไม่สร้าง CRUD framework, member requests/payment จริง, Conference staff tab, distributed broker หรือ cross-domain SQL transaction; ไม่ทำ live migrations/deployments ระหว่างงาน refactor
- Paths ด้านล่าง relative ต่อ monorepo เป้าหมาย; source references เป็น absolute paths ของ repositories เดิม ไม่มีการเปลี่ยน production จากเอกสารนี้
- Foundation ที่ต้องมี: `buildApp({config?,db?,clock?})`, `getServerConfig()`, `resolveStaffActor(jwt)`, `requireCapability(key)`, `browserApi<T>(path,options)`, `backendFetch<T>(path,options)`, `ApiError`, `CAPABILITY`/`PermissionKey`; รักษาค่า legacy capability keys
